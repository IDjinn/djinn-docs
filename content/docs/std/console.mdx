## Overview

The `Console` struct in `std::sys` provides standard I/O operations. It supports both synchronous and async output, with a buffered formatting system that handles `{0}`, `{1}`, etc. placeholders.

```djinn
import std::sys;
```

## Formatted Output

`writeSync`, `write` and `format` support indexed placeholders `{0}`, `{1}`, etc. with variadic arguments. The formatter is plain Djinn: it reads each argument's `TypeInfo` and prints signed and unsigned integers of every width, `bool` as `true`/`false`, floats with the same shortest round-trip text as string interpolation, and `str`, `string` and `i8*` text. A placeholder whose index has no argument prints nothing.

The three methods share one formatter that fills a buffer and hands it back to the caller: `writeSync` writes it with `write`, `write` submits it to the runtime's event loop, and `format` grows a heap buffer and returns it as a NUL-terminated `str`. Text longer than the 8 KB buffer is streamed in pieces, so nothing is truncated. Only the async methods use the Djinn runtime.

```djinn
import std::sys;

void main() {
    Console.writeSync("Hello {0}, you are {1} years old\n", "Alice", 30);
}
```

## Async I/O

The async methods use the Djinn runtime's event loop for non-blocking I/O:

```djinn
import std::sys;

async void main() {
    await Console.write("Enter your name: ");
    void* input = await Console.readLine();
    await Console.write("Hello, {0}!\n", (i8*)input);
}
```

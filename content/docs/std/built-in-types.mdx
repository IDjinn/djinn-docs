### Primitive Constants

All numeric types expose `MAX_VALUE` and `MIN_VALUE` constants. Floating-point types also expose `MIN_POSITIVE` and `EPSILON`:

```djinn
i32 max = i32.MAX_VALUE;   // 0x7FFFFFFF
i32 min = i32.MIN_VALUE;   // 0x80000000
u64 umax = u64.MAX_VALUE;  // 0xFFFFFFFFFFFFFFFF

f64 eps = f64.EPSILON;          // 2.2204460492503131e-16
f32 minPos = f32.MIN_POSITIVE;  // 1.17549435e-38
```

`str` and `string` hash the same text to the same value, so a `map<str, V>` can be looked up with either. The hash
reads the text eight bytes at a time and is not stable across compiler versions; do not store it.

## Interning

`std::text` has an interner: it keeps one copy of each distinct text and hands out a `symbol`, an 8-byte handle to
that copy. Two symbols from the same interner are equal exactly when their handles are equal, so comparing them never
reads the text, and the hash is stored with the text. Interning pays off when the same texts repeat many times
(tokens, JSON keys, CSV categories); for texts that are mostly unique it costs more time and memory than plain
strings, so it is opt-in.

```djinn
import std::text;

i32 main() {
    interner pool = interner();          // scoped: freed when `pool` goes out of scope
    symbol a = pool.intern("name");
    symbol b = pool.intern("na" + "me");
    // a == b, and a.entry == b.entry
    pool.clear();                        // drops every text; a and b are no longer valid

    symbol shared = interner.shared("name");   // the global interner, lives for the whole program
    interner.clear_shared();
    return 0;
}
```

## Reflection

### TypeInfo

```djinn
struct TypeInfo {
    i32 id;
    i32 size;
    i8* name;
    u8 kind;
}
```

Runtime type metadata available via the `typeof` intrinsic. The `kind` field encodes the category: `0` = integer, `1` = float, `2` = pointer.

### object

```djinn
struct object : Hashable {
    TypeInfo* type;
    void* data;
}
```

A type-erased value with runtime type information. Used internally by variadic functions to inspect argument types at runtime.

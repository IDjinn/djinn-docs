## Overview

`std::sys` provides `atomic<T>`, `atomic_bool` and `Atomics.fence()`. They are thin wrappers over the
[atomic intrinsics](/docs/std/instrinsic#atomic-operations): every method inlines to a single LLVM atomic instruction,
with no call into the runtime, so they work the same in native, runtime and JIT builds.

```djinn
import std::sys;

i32 main() {
    atomic<i32> hits = atomic<i32>(0);
    hits.fetchAdd(1);
    if (hits.compareExchange(1, 10)) {
        return hits.load();
    }
    return 0;
}
```

## atomic&lt;T&gt;

## atomic_bool

`atomic_bool` stores one byte and offers `load`, `store`, `exchange` and `compareExchange` with `bool` values.

## Ordering

Every operation is sequentially consistent. `Atomics.fence()` emits a full memory barrier.

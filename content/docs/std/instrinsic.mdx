## Intrinsics

Intrinsics is any special case which compiler may override or re-write its implementation
based on what is known at that build process. The porpuse is make possible some sort of flexibility
when doing compilation through source code

## Atomic operations

The `atomic_*` intrinsics compile straight to LLVM atomic instructions (`atomicrmw`, `cmpxchg`, `load atomic`,
`store atomic`, `fence`), all sequentially consistent, so they need no runtime library. `T` is an integer of 8 to 64
bits or a pointer; the arithmetic and bitwise forms take integers only. Anything else is error `E3059`.

```djinn
i32 main() {
    mut i64 counter = 5;
    i64 previous = atomic_add(&counter, 3);
    bool stored = atomic_cas(&counter, 8, 10);
    return (i32)atomic_load(&counter);
}
```

`std::sys` wraps them in [`atomic<T>`](/docs/std/atomic) for code that prefers methods.

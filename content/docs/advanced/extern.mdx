## Extern Functions

Use `extern "C"` to declare C functions that can be called from Djinn:

```djinn
extern "C" {
    i32 printf(i8* format, ...);
    i32 puts(i8* s);
    void* malloc(size_long size);
    void free(void* ptr);
}
```

These are linked at compile time against the C standard library.

## Redeclaring an Extern

Declaring the same extern function twice (for example `strlen`, which the standard library already declares) is allowed when the declarations match: it only reports a warning (`E6002`) and the first declaration is kept. A redeclaration with a different return type, different parameter types or a different variadic flag is an error (`E3003`). Pointer types are compared by ABI, so `void*`, `i8*` and `ptr<i8>` count as the same type.

## Runtime Allocators

The runtime exports two allocators that trap on out-of-memory instead of returning `null`:

Both are released with `free` (or `__djinn_free`). The compiler marks them as allocators for LLVM
(`allockind`, `allocsize`, `noalias`), wherever they are declared, so at `-O1` and above a zero fill right after
`__djinn_alloc_zeroed` is removed and an allocation whose result is never used can be dropped.
`__djinn_malloc` is the old name of `__djinn_alloc_zeroed` and stays exported only for code built by an older compiler.

## Calling Extern Functions

Extern functions are called like regular Djinn functions:

```djinn
extern "C" {
    i32 printf(i8* format, ...);
}

i32 main() {
    printf("Hello %s! Answer: %d\n", "World", 42);
    return 0;
}
```

## Variadic Functions

C variadic functions (like `printf`) are supported with `...`:

```djinn
extern "C" {
    i32 printf(i8* format, ...);
    i32 sprintf(i8* buf, i8* format, ...);
}
```

## Math Library

C math functions are available through extern declarations:

```djinn
extern "C" {
    f64 sqrt(f64 x);
    f64 pow(f64 base, f64 exp);
    f32 sqrtf(f32 x);
}
```

## Standard Library

The standard library wraps common extern declarations. Import them directly:

```djinn
import std::types;
import std::libc;

i32 main() {
    printf("Using std::libc\n");
    return 0;
}
```

See [Built-in Types](/docs/std/built-in-types) for the full standard library reference.

## Native errors

`[NativeError(detect = <condition on result>, capture = errno | last_error | return_code)]` on an extern function that
declares `throws(E)` makes a failed call throw `E { .code = <captured> }`, so `try` and `switch` handle it like any
Djinn error. `E` is a struct with an integer field `code`. `errno` is cleared before the call and read right after it;
`last_error` is `GetLastError` on Windows (errno elsewhere); `return_code` uses the returned value.

```djinn
struct OsError {
    i32 code;
}

extern "C" {
    [NativeError(detect = result != 0, capture = errno)]
    i32 remove(i8* path) throws(OsError);
}

unsafe i32 main() {
    return switch remove("missing.txt") {
        Result v -> 0,
        OsError e -> e.code
    };
}
```

A malformed attribute (no `detect`, an unknown `capture`, no `throws`) is `E7012`.
